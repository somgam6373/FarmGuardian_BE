### Record / Browse / Edit
- Record: 「이 약 쓸게요」 원탭 → spray_log insert (기본 오늘). 취소 = 삭제.
- Browse: 구역 목록(상태 요약) → 구역 상세(편중도 + 최근 판정 + 이력). 수동 구역은 개략 배치도.
- Edit: 구역 수정(작물 변경 시 새 작기 확인, 수동 구역에 필지 나중 연결), 구역 분할(기존 구역을 필지 묶음별로 나눔, 이력은 새 구역 모두에 복사), 이력 수정·삭제.

## 2. 주소 → PNU 변환 (도로명주소 API)

- 엔드포인트: `https://business.juso.go.kr/addrlink/addrLinkApi.do` (승인키 `confmKey`, `keyword`, `resultType=json`, `currentPage`, `countPerPage`)
- 응답에서 쓸 필드: `admCd`(10자리 법정동코드), `lnbrMnnm`(지번 본번), `lnbrSlno`(지번 부번), `mtYn`(산 여부 0/1), `jibunAddr`, `roadAddr`
- PNU(19자리) = `admCd`(10) + 필지구분(1) + 본번(4, 0 패딩) + 부번(4, 0 패딩)
  - 필지구분: mtYn=0 → `1`(대지), mtYn=1 → `2`(산)
- 호출은 반드시 서버에서 (승인키 노출 방지). 키 발급·유효기간·일일 한도는 신청 시 확인할 것.
- 농지는 도로명이 없는 경우가 많으므로 검색창에 「동/리 + 지번」 입력 안내를 표시.
- 구현 후 확인할 것: 실제 농지 지번 몇 건으로 PNU를 조립해 팜맵 `getPnuBasedFarmmapInfo`가 필지를 돌려주는지 테스트.
- 팜맵 PNU 조회는 해당 지번과 **중첩되는 팜맵 필지 전체**를 돌려준다 (기술문서 기준). 이웃 지번의 필지가 섞여 오고, 한 지번이 판독(논·밭 등)이 다른 필지 여러 개일 수 있다. 구역의 단위는 지번이 아니라 팜맵 필지(`fmapInnb`)다.

## 3. 판정 규칙 (코드로 옮길 형태)

> 2026-10-04 이후 세부 확정 규칙 (② 수확 가능일 표시, ③ 품목명 기준 합산, ④ 임계값, 편중도, 대안, 문구)은 `farmguardian_judge_rules.md`가 우선한다. 아래와 충돌하면 그 문서를 따른다.

- 우선순위: 불가 > 확인 필요 > 주의 > 가능
- ① 등록 / ② 시기 / ③ 횟수 = 법·출하 문제. ④ 작용기작 = 효과 문제.
- ③ 집계 범위: 일년생 = zone.planted_at 이후, 다년생 = 올해 1/1 이후. 작물 변경 시 0부터 재시작.
- ④ 집계: 구역 전체 이력의 최근 3회. 출력 예 「가1 (FRAC 4) — 최근 3회 중 2회」. 확률 표기 금지.
- 이력 0건 + 「뿌린 적 없음」 미선택 → ③④는 확인 필요.
- 병해충 미지목 시: PHI=해당 작물·약제 행 중 최댓값, 최대횟수=최솟값. 화면에 「병해충을 지정하지 않아 가장 엄격한 기준을 적용했습니다」 표시.
- 결과 화면 필수 표시: 근거 원문, 데이터 기준일, 불가 약제의 사유, 불가·주의 시 다른 작용기작 대안. 대안 0건일 때만 「농업기술센터 문의」.
- 문구 규칙: 예측·추천 표현 금지.
- 화면 안내 한 줄: 「횟수는 정식일(다년생은 올해 1월 1일) 이후 기준으로 집계합니다」

## 4. 데이터 모델 변경점

- `crop.is_perennial boolean` 추가 (지원 작물 목록 확정 시 함께 채움)
- `zone`: 팜맵 필지 연결은 nullable (`farmmap_ids` 또는 별도 연결 테이블), 수동 구역은 `manual_area_m2` 또는 가로·세로 보유
- `spray_log`는 geometry와 무관하게 zone_id만 참조
- 면적: PostGIS `ST_Area`로 계산 (필지는 `geometry(MultiPolygon, 5179)`로 저장하므로 결과가 ㎡). 수동 구역은 입력한 면적 사용
