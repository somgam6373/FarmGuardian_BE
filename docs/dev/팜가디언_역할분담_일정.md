# 팜가디언 백엔드 역할 분담

## 혜빈님: 팜맵 + 밭·구역

| 영역 | 내용 |
|---|---|
| 외부 연동 | `farm/infrastructure/integrations/`의 `vworld.py`(브이월드 지번 검색), `farmmap.py`(팜맵 클라이언트, GML 파서) |
| API | `GET /addresses/search`, `GET /parcels` |
| 밭 | `farm/application/field_service.py`: 밭 생성·목록·삭제 (`POST /fields`, `GET /fields`, `DELETE /fields/{id}`) |
| 구역 분할 | `farm/domain/split.py`(분할 순수 함수), `POST /fields/{id}/split-preview`, `POST /fields/{id}/zones` |
| 구역 상세·수정 | `farm/application/zone_service.py`: 구역 상세·수정 (`GET /zones/{id}`, `PATCH /zones/{id}`) |

## 준혁: 나머지 전부

| 영역 | 내용 |
|---|---|
| 기반 | `core`(설정·DB·에러·`today_kst`), DB 스키마·마이그레이션, 개발 DB·테스트 DB |
| `identity` | 가입·로그인, 온보딩 상태, 회원 탈퇴 (`/auth/*`, `/me*`) |
| `farm` 날씨 | 구역 날씨 (`GET /zones/{id}/weather`), 기상청 연동 `kma.py` |
| `catalog` | 엑셀 → JSON → DB 적재, 작물·병해충·약제 조회 |
| `judgment` | 4체크 판정, 판정 API |
| `spraying` | 살포 기록 저장·조회·취소 |
| 기타 | `seed_demo`, API 명세(`openapi.json`), 기획·프론트 협의 |
